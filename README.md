# ORIGINA Plagiarism & 24-Language AI Detection Plugin for OJS 3.x

Official Open Journal Systems (**OJS 3.3 / 3.4**) generic plugin for **[ORIGINA](https://origina.app)** — enabling journal editors to verify manuscript similarity, direct AI writing, AI-paraphrased passages, and hidden text forensics directly inside the editorial workflow with a strict **100% No-Repository** policy.

> **Official Integration Guide & API Keys:** https://origina.app/ojs-integration.html

## Key Features
- **100% No-Repository Policy:** Manuscripts are never stored in any shared database.
- **24-Language AI & Paraphrase Detection:** Calibrated multilingual detection for global academic journals.
- **Live Web & Scholarly Similarity:** CrossRef & OpenAlex matching with bibliography/quote exclusion.
- **Cheat Shield Forensics & QR Certificates:** Flags hidden text/homoglyphs and generates verifiable HMAC-SHA256 certificates.

## Installation (OJS 3.3 / 3.4)
1. Download `origina-ojs3-plugin.tar.gz` from the **Releases** page (or from https://origina.app/ojs-integration.html).
2. In OJS, go to **Settings → Website → Plugins → Upload A New Plugin**.
3. Upload `origina-ojs3-plugin.tar.gz`, click **Save**, and enable **ORIGINA** under **Generic Plugins**.
4. Open **Settings**, set API URL to `https://origina.app`, and paste your API Key.
